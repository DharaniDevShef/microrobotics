For connections, look up the json file by loading it and getting connector between modules
based on the connector number, get the body name of the connector and add a weld between them.
based on connector, assign current module  mesh="connectorA" and connecttor of the next module mesh="connectorB"
also connection happens only when one connector is A and the other is B.
assign mesh="connectorC" to the remaining connector of the module which is not connected to any other module.
based on where another module is connected, the angle of the next module connected would change.
pick a base module as module_1 and compute the pos and quat of all other modules connected to it. 
The pos and quat of modules connected are computed with respect to base module

ignore the _ properries in the json and load it as 
# ----------------------------
# Load JSON
# ----------------------------
with open("beetle_graph.json", "r") as f:
    data = json.load(f)

# ----------------------------
# Create Directed Graph
# ----------------------------
G = nx.DiGraph()

for node in data["nodes"]:
    G.add_node(
        node["id"],
        module_type=node["module_type"],
        hinge_angle=node["hinge_angle"],
        pos=node["_pos"]
    )

for edge in data["edges"]:
    G.add_edge(
        edge["source"],
        edge["target"],
        connector1=edge["connector1"],
        connector2=edge["connector2"]
    )
