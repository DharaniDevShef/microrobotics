
**Title: Evolution of Robotic Locomotion through Morphological Optimisation

Project Aim:

This project aims to develop an ML-assisted evolutionary framework within the existing self-assembling modular robotic platform to design and optimise two-dimensional module morphologies that self-assemble and self-fold into three-dimensional robots capable of magnetic locomotion. The work addresses the limited integration between morphology generation, self-folding behaviour, and locomotion performance in existing evolutionary robotic approaches, and seeks to investigate how morphological evolution influences locomotion behaviour and robotic functionality, with potential applications in adaptive modular robotic systems and automated robotic design.

Basic Objectives:

1. O-1: Develop an ML-assisted evolutionary approach using Python to generate and evolve two-dimensional self-assembling module configurations, with the specific ML approach to be selected following a review of relevant literature.
2. O-2: Extend the existing simulation framework to enable self-folding of two-dimensional module configurations into three-dimensional robotic structures.
3. O-3: Extend the existing simulation framework to evaluate three-dimensional robotic structures within a physics-based simulation environment and actuate them using an oscillating magnetic field to achieve locomotion performance. Feed the resulting fitness values back into the evolutionary framework.
4. O-4: Analyse the evolution of robotic morphologies and investigate their influence on locomotion behaviour and performance using performance-based metrics across generations

Advanced Objectives:

1. AO-1: Investigate and compare different ML surrogate-learning approaches for morphology fitness prediction and evaluate their influence on optimisation efficiency and evolutionary performance. - Changed to adapt Phermone metrics for evolution
2. AO-2: Investigate entropy and morphology-complexity measures and analyse their relationship with locomotion behaviour and evolutionary outcomes.
